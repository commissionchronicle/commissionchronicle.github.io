# The Commission Chronicle

The Commission Chronicle is Los Santos' weekly crime paper — the families, the commissions, and every claim to a seat at the table, printed as claims and never as verdicts.

New editions every Wednesday. This site is the paper's public archive: each edition lives in its own dated folder, and the homepage carries the latest.

- **Latest edition:** see the homepage.
- **On Instagram:** [@gtarpnoticeboard](https://www.instagram.com/gtarpnoticeboard)
- **Event calendar and more:** via the paper's Linktree, linked from the Instagram page.

Offices at La Mesa.
